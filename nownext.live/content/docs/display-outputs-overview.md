# Display Outputs Overview

NowNext.live generates specialized display views tailored for different roles in your venue. Rather than giving everyone access to the controller, **Output Links** deliver clean, read-only displays customized for presenters, players, spectators, and broadcast streams.

---

## Available Output Views

### 1. Main Display (`/r/[id]`)
- **Purpose**: Full-venue overview showing "NOW" and "NEXT" sessions for all active spaces side by side.
- **Ideal For**: Main entrance hall screens, spectator lounge Smart TVs, central scoreboard monitors.

### 2. Space / Court Display (`/r/[id]?space=[space_id]`)
- **Purpose**: High-contrast, single-space view focusing strictly on one court or room.
- **Ideal For**: Tablet screens mounted beside Court 1, outside Seminar Room B, or stage confidence monitors.

### 3. Full Schedule Grid (`/r/[id]/schedule`)
- **Purpose**: Full matrix schedule showing times, spaces, and complete daily fixture lists.
- **Ideal For**: Spectator QR code scans, participant smartphones, information desk kiosks.

---

## Accessing & Sharing Output Links

### Output Links Modal
From your **Controller Dashboard**, tap the **Output Links** button in the header toolbar to open the share modal:

- **Copy Link**: Instantly copies the full HTTPS link to clipboard for emailing or pasting into Smart TV browser address bars.
- **Open in New Tab**: Preview how the display looks before sending to a remote TV.
- **QR Code Generator**: Display a scannable QR code for spectators to scan on their smartphones.

---

## Display Configuration & Layout Options

- **Auto-Fit Typography**: Text scales automatically to maximize legibility regardless of screen resolution.
- **Dark & Light Mode Support**: High-contrast light mode for brightly lit sports halls; dark mode for auditorium confidence monitors.
- **Fullscreen Execution**: Press `F11` (Windows/Linux) or `Control + Command + F` (macOS) to hide browser toolbars and tabs.
