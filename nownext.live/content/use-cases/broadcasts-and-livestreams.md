# On-Air Rundown Displays for Broadcast Studios & Livestreams

In live broadcast, podcast, and livestream environments, smooth timing and talent coordination are paramount. Presenters need clean visual cues for current segments (**NOW**) and upcoming topics (**NEXT**), while producers need instant control over the studio rundown. **NowNext.live** functions as a flexible browser-based studio confidence monitor and rundown display.

---

## Content Outline

### 1. Introduction: The High-Pressure World of Live Broadcast
- **The Challenge**: Live talent missing time cues, unscripted segment overruns, and crew miscommunication.
- **Traditional Workarounds**: Complex AV timing hardware or expensive proprietary broadcast software.
- **The Modern Studio Need**: A lightweight, real-time visual cueing system accessible on studio monitors and teleprompter displays.

### 2. Studio Capabilities of NowNext.live
- **Talent Confidence Monitors**: Clean, high-contrast visual displays showing the active segment and next topic.
- **Producer Rundown Control**: Remote control interface allowing producers or floor directors to trigger segment changes instantly.
- **Multi-Camera & Remote Crew Access**: Web links allow off-site producers, remote guests, or technical directors to view synchronized studio status.

### 3. Key Benefits for Production Teams
- **Browser-Native Simplicity**: Runs natively inside OBS Studio, vMix, smart monitors, or browser dockables.
- **Real-Time Latency**: Built on Supabase real-time channels for instant state synchronization between control room and studio floor.
- **Flexible Presentation**: Minimalist, distraction-free typography optimized for camera confidence monitors.

### 4. Studio Setup & Workflow Guide
1. **Set Up Show Rundown**: Define segments (e.g., Intro, Guest Interview, Product Demo, Q&A, Outro).
2. **Assign Studio Monitors**: Open display URLs on confidence monitors facing talent.
3. **Control Live Flow**: Floor manager or producer advances rundown items as the live stream progresses.
